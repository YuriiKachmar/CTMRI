# CTMRI

Програма обліку КТ/МРТ-досліджень. Один файл `index.html`, Firebase (проєкт `ctmri-1`), GitHub Pages.

## Стан

Етап 1: вхід (4 режими), перший запуск (перший користувач = Керівник), майстер налаштування закладу, оболонка програми.
Далі: Журнал, довідники, звіти.

## Файли

- `index.html` — вся програма.
- `firestore.rules` — правила бази (вставляються в Firebase Console → Firestore → Rules).

## Запуск

GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)`.
Адреса: https://yuriikachmar.github.io/CTMRI/

## Рішення

- **Тільки безкоштовні ресурси** (Firebase Spark, GitHub Pages). Нічого, що вимагає тарифу Blaze (Cloud Functions, Storage), не використовуємо. Лого зберігатимемо в Firestore, а не в Storage. По завершенню проєкту — перерахунок обсягів даних і рішення про платформу.
- Один HTML-файл `index.html` на всю програму.
- Довідники не видаляються, лише переводяться в «Не активна» (минулі візити посилаються на знімки значень).
- Тестових даних у програмі немає: все вводиться вручну.

## Відомі спрощення

- Права на довідники тимчасово: редагують Керівник і Адміністратор. Далі — з матриці «Доступи».
- Пільги: зберігається поле `effectiveFrom`, але історії версій відсоток не має. Минулі візити мають знімок пільги (`discountSnapshot`), тож звіти не залежать від зміни довідника.
- `audit_log` пишеться, але правила Firestore ще дозволяють його редагувати (звузити за ролями).
