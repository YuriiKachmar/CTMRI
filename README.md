# CTMRI

Програма обліку КТ/МРТ-досліджень. Один файл `index.html`, Firebase (проєкт `ctmri-1`), GitHub Pages.

## Стан

Етап 1: вхід (4 режими), перший запуск (перший користувач = Керівник), майстер налаштування закладу, оболонка програми.
Далі: Журнал, довідники, звіти.

## Файли

- `index.html` — вся програма.
- `firestore.rules` — правила бази (вставляються в Firebase Console → Firestore → Rules).

## Запуск

GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)`.
